# CallScope HF website

Public static website for the CallScope HF desktop test programme.

Deploy only the validated compiled website export to this repository. Desktop installers and
updater assets are published separately in [callscope-releases](https://github.com/wolkjesmelker/callscope-releases).
Do not add the application source checkout, environment files, credentials or local user data.

The intended site URL is https://wolkjesmelker.github.io/.
